# FlowGuard

An early prototype for automation reliability.

> Don't just tell me an automation failed. Tell me whether the business outcome is actually safe.

## Current build
This is a local-only front-end MVP. It demonstrates workflow health, incident prioritization, search, and the product thesis. It does not collect API keys or contact external providers.

## Run
Open index.html directly or use VS Code Live Server.

## Next
Real provider adapters, scheduled checks, authentication, encrypted secrets, persistent storage, alerts, outcome checks, and billing.

Never commit secrets, tokens, passwords, or database credentials.
